# 💚 Ilya's:Shell 🐚

**Модульная оболочка для терминала, написанная на Python 3. С душой, цветами и птицами.**

---

## ✨ Особенности

- **Две оболочки в одном флаконе**:  
  - `ilya's:cmd_` — первая версия, простая и быстрая. Останется легендой навсегда. 
  - `💚 Ilya's:Shell 🐚` — улучшенная, модульная, с поддержкой пользовательских команд.

- **Команды с душой**:  
  - `kill` — убить кого-нибудь.  
  - `revive` — воскресить с драматической задержкой.  
  - `whoami` — с пасхалкой для создателя.  
  - `guess` — игра "угадай число".  
  - `rng` — генератор случайных чисел.  
  - `binary` — конвертер в двоичную систему.  
  - `calc` и `pifagor` — встроенные модули.

- **Пользовательские команды**:  
  Добавь свои функции в `config.py` — и они появятся в оболочке.

- **Цветной вывод**:  
  ANSI-цвета делают общение с терминалом ярким и живым.

- **История команд**:  
  Все введённые команды сохраняются в `.history_file`.

## 📦 Установка

### 1. Клонируй репозиторий
```bash
git clone https://github.com/IMAMCHA1N1K/Ilyas-Shell.git
cd Ilyas-Shell
```
### 2. Запусти оболочку
```bash
python IlyasShell.py
```
Или с правами на выполнение:
```bash
chmod +x IlyasShell.py
./IlyasShell.py
```

## ⚙️ Конфигурация

- **Все настройки лежат в ./configs/configShell.py**:

    - Цвета

    - Промпт

    - Список "неприкасаемых" (кого нельзя убить)

    - Пользовательские команды

## 🐦 Чижик и Пыжуля

- **Оболочка создавалась под присмотром двух волнистых попугаев**:

    - Чижик — зелёный, шумный, наглый. Главный тестировщик.

    - Пыжуля — жёлтая, мудрая, тихая. Вдохновитель.
